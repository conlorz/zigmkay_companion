# Package E: guided curriculum review

Curriculum v1 introduces six selectable stages and a deterministic constrained
generator over the existing first-party vocabulary. A useful ordered alphabet
starts with six reachable base letters and expands one at a time. Capitals,
shifted punctuation, layers and modifier families introduce one proven output
while retaining familiar words. Family-specific guidance prefers the requested
route; text scoring still does not prove physical execution. Real text validates
every generated character's route, including the existing Zig lessons.

Length, assistance and manual progression remain independent. Repeated occurrence
evidence gates recommendations; later stages also require recent clean timing
calibration. The policy is explicitly hypothetical for manual validation. It
never automatically demotes a selected stage or equates guided success with
unaided mastery. Immutable run contexts restore the last completed normal lesson.

Database schema 2 adds an indexed broad practice scope for curriculum restoration
while keeping exact progress cohorts separate. Schema setup/migration starts an
immediate transaction before reading the version, preventing concurrent writers
from racing the migration. The original cohort key remains stable for older
records; defaulted context fields cannot hide old history. Duplicate identity
uses validated semantic records instead of comparing changing serialized defaults.
Legacy raw bytes and migration receipts remain preserved. Readonly schema 1
sources can still be imported. Invalid migration input rolls back schema/data
changes; future versions remain unsupported.

Review checked alphabet bounds, corpus coverage, Unicode family outputs,
compatible distinct providers, reproducibility, route preference, canonical
context, challenge isolation and separate stage/assistance history. Tests cover
all six stages and lengths, recommendations, restoration across reopen, old-byte
identity, complete migration rollback and independent concurrent writers.

Native wide/small lesson selection and introductory exercise were compared with
the E mockup. Screenshot review shortened the evidence checklist and removed the
irrelevant speed counter from Find keys. It also exposed the pinned DVUI wrapped
text widget freeing an advanced borrowed slice when text was offscreen. Measured
UTF-8 labels now provide wrapping without that path or changing the dependency.

Validation: exact Zig 0.17.0, native practice/data contracts, full local offline
checks, desktop build and existing native offline fixtures. Screenshots are linked
from the tutor guide. Real hardware/provider ergonomics remain manual acceptance.
